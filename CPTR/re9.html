Requirement 9 — BONUS: [BONUS] Windows Terminal Services / Remote Desktop Services

Step-by-Step Procedure:

  1. SERVER: Right-click This PC → Properties → Remote settings → ✔ Allow remote connections
  2. System Properties → Remote → Select Users → Add: Administrator, Domain Admins
  3. Windows Firewall → Allow app → ✔ Remote Desktop
  4. CLIENT VM: Win+R → mstsc → Server: SERVER-IP or SERVERNAME
  5. Login: Administrator or DOMAIN\Admin → Connect → Full remote control ✅
